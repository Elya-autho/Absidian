
### Шаг 1. Проверка системных требований

1. **Операционная система:** Windows 10 (версия 21H2 и выше) или Windows 11 (Home, Pro, Enterprise или Education).
    
2. **Аппаратная виртуализация:** В BIOS/UEFI материнской платы должна быть включена виртуализация (Intel VT-x или AMD-V).
    
    - _Как проверить:_ откройте «Диспетчер задач» $\rightarrow$ вкладка «Производительность» $\rightarrow$ строка «Виртуализация» должна иметь значение **«Включено»**.


### Шаг 2. Включение компонентов WSL 2 (рекомендуется)

Большинству пользователей рекомендуется использовать бэкенд **WSL 2** (Windows Subsystem for Linux), так как он работает быстрее и потребляет меньше ресурсов.

1. Откройте PowerShell или **Командную строку** от имени **администратора**.
    
2. Выполните команду для включения подсистемы Linux и компонента виртуальной машины:
    
    PowerShell
    
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
    
3. **Перезагрузите компьютер**, чтобы изменения вступили в силу.
    
4. Скачайте и установите обновление ящика Linux для WSL 2 (если потребуется, установщик Docker предложит сделать это автоматически, но можно сделать заранее по [официальной ссылке Microsoft](https://aka.ms/wsl2kernel)).


### Шаг 3. Скачивание и установка Docker Desktop

1. Перейдите на официальный сайт [Docker Hub](https://www.docker.com/products/docker-desktop/) и скачайте установщик **Docker Desktop for Windows**.
    
2. Запустите скачанный файл `Docker Desktop Installer.exe`.
    
3. В процессе установки мастер предложит выбрать параметры:
    
    - Обязательно оставьте галочку **«Use WSL 2 instead of Hyper-V»** (рекомендуется).
        
    - При желании можно настроить установку для конкретного пользователя или всех пользователей системы.
        
4. Нажмите **OK** и дождитесь завершения распаковки файлов.
    
5. По завершении установки нажмите **Close and restart** для перезагрузки ПК (если потребуется).
    

### Шаг 4. Первый запуск и проверка

1. После перезагрузки **Docker Desktop** должен запуститься автоматически. Если этого не произошло, найдите его через меню «Пуск».
    
2. При первом запуске появится окно с принятием пользовательского соглашения (**Accept**).
    
3. Программа предложит войти в учетную запись Docker Hub — этот шаг **можно пропустить** (нажмите _Continue without signing in_), если у вас нет аккаунта.
    
4. Подождите пару минут, пока в нижнем трее панели задач иконка Docker (кит с контейнерами) не перестанет мигать и не станет зеленой (статус _Docker Desktop is running_).
    

### Шаг 5. Проверка работоспособности в терминале

Откройте **PowerShell** или обычную командную строку (`cmd`) и выполните тестовые команды:

1. Проверить версию Docker и клиента:
    
    Bash
    
    ```
    docker --version
    ```
    
2. Запустить тестовый контейнер «Hello-World», чтобы убедиться в правильности настройки:
    
    Bash
    
    ```
    docker run hello-world
    ```
    

Если установка прошла успешно, вы увидите приветственное сообщение от Docker, подтверждающее, что контейнер успешно скачался и запустился. Теперь вы можете использовать привычные команды Docker и работать с контейнерами прямо в Windows.
