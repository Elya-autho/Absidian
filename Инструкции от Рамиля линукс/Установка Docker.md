Дублирую адаптированную пошаговую инструкцию для развертывания этого прокси-клиента на **Linux**.

1. Создание структуры проекта

Откройте терминал и создайте рабочую директорию одной командой:

bash

```
mkdir -p ~/tg-vpn-proxy && cd ~/tg-vpn-proxy
```

Используйте код с осторожностью.

2. Создание файлов конфигурации

```

      "listen": "0.0.0.0",
      "protocol": "socks",
      "settings": {
        "auth": "noauth",

      }
    }
  ],
  "outbounds": [
    {
      "protocol": "vless",
      "settings": {
        "vnext": [
          {
            "address": "89.125.24.175",
            "port": 443,
            "users": [
              {
                "id": "43f19854-9311-4064-bbaf-cca7dab4e6d0",
                "encryption": "none",
                "flow": "xtls-rprx-vision"
              }
            ]
          }
        ]
      },
      "streamSettings": {
        "network": "tcp",
        "security": "reality",
        "realitySettings": {
          "fingerprint": "firefox",
          "serverName": "google.com",
          "publicKey": "aBgUKoFnYyscJkcJ2tna_mGFXfAMXv_dBp5CbLIummo",
          "shortId": "7d",
          "spiderX": ""
        }
      }
    }
  ]
}
EOF
```

Используйте код с осторожностью.

Создайте манифест `docker-compose.yml` для управления контейнером Xray:

bash

```
cat << 'EOF' > docker-compose.yml
services:
  vless-client:
    image: teddysun/xray:latest
    container_name: xray-vless-socks
    restart: unless-stopped
    ports:
      - "1081:1080"
    volumes:
      - ./config.json:/etc/xray/config.json
EOF
```

Используйте код с осторожностью.

3. Запуск прокси-клиента

Запустите контейнер в фоновом режиме (флаг `-d`):

bash

```
docker compose up -d
```

Используйте код с осторожностью.

_(Если ваша версия Docker не поддерживает новый синтаксис, используйте старую команду через дефис: `docker-compose up -d`)_

4. Проверка состояния

Выведите логи контейнера в реальном времени, чтобы убедиться в отсутствии ошибок подключения:

bash

```
docker compose logs -f
```

Используйте код с осторожностью.

Для выхода из режима просмотра логов нажмите сочетание клавиш **Ctrl + C**.

5. Параметры подключения в Linux

Клиент принимает входящие соединения локально со следующими данными:

- **Адрес:** `127.0.0.1` (или `localhost`)
- **Протокол:** `SOCKS5`
- **Порт:** `1081`

**Способы применения:**

- **В Telegram:** Перейдите в _Настройки -> Продвинутые настройки -> Тип подключения -> Использовать собственный прокси -> Добавить прокси_. Выберите тип **SOCKS5**, укажите хост `127.0.0.1` и порт `1081`.
- **В браузерах:** Установите расширение вроде **FoxyProxy** или **SmartProxy**, чтобы заворачивать в прокси только заблокированные ресурсы.
- **Для консольных утилит:** Чтобы пустить отдельную команду терминала через этот прокси, используйте утилиту `proxychains` или задавайте переменные окружения, например: `ALL_PROXY=socks5://127.0.0.1:1081 curl ifconfig.me`.

Если контейнер **не запускается** или логи показывают ошибки соединения с сервером (например, `context deadline exceeded`), сообщите об этом. Нужен ли вам **скрипт автоматического перезапуска** контейнера при сбое сети?
