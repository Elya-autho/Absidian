Шаг 1: Подготовка папок и файлов  
Открой терминал и создай рабочую директорию с нужной структурой  

mkdir -p ~/awg-proxy/config/wg_confs

  
Перейди в созданную корневую папку:  

cd ~/awg-proxy

  
Создание конфигурации VPN (`awg0.conf`)  
Нужно перенести тот самый рабочий конфиг AmneziaWG.  
Открой текстовый редактор `nano`, чтобы создать файл:  

nano ~/awg-proxy/config/wg_confs/awg0.conf

  
-Вставь туда содержимое конфига. **Критически важно:** вспомни ошибку парсинга, с которой мы столкнулись. В самом конце блока `[Interface]` **не должно быть пустых строк** вроде `I2=`, `I3=`. Оставь только те параметры, где есть значения, иначе Linux-утилита внутри докера снова упадет. Также убедись, что прописаны надежные публичные DNS: `DNS = 1.1.1.1, 8.8.8.8`.  
-Сохрани файл: нажми `Ctrl+O`, затем `Enter`, затем `Ctrl+X` для выхода.  
Создание `docker-compose.yml`  
Теперь создадим итоговый файл компоуза, в котором уже учтен измененный порт (от конфликтов) и добавлена обязательная авторизация.  
Открой редактор:  

nano ~/awg-proxy/docker-compose.yml

  
Вставь этот готовый блок:  

version: '3.8'

services:
  amneziawg:
    image: ghcr.io/ayastrebov/docker-amneziawg:latest
    container_name: awg-client
    cap_add:
      - NET_ADMIN
    devices:
      - /dev/net/tun:/dev/net/tun
    volumes:
      - ./config:/config
    sysctls:
      - net.ipv4.ip_forward=1
      - net.ipv4.conf.all.src_valid_mark=1
    ports:
      - "10809:1080" # Внешний порт 10809, чтобы не было конфликтов
    restart: unless-stopped

  socks5:
    image: serjs/go-socks5-proxy
    container_name: awg-socks5
    network_mode: "service:amneziawg"
    environment:
      - PROXY_USER=admin
      - PROXY_PASSWORD=admin
    depends_on:
      - amneziawg
    restart: unless-stopped

  
Сохрани: `Ctrl+O`, `Enter`, `Ctrl+X`  
Запуск контейнеров  
Убедись, что ты находишься в папке `~/awg-proxy`, и запускай стек. На Ubuntu для докера обычно требуются права суперпользователя:  

sudo docker compose up -d

  
Сразу после запуска можешь проверить логи, чтобы убедиться, что туннель поднялся без ошибок парсинга:  

sudo docker logs awg-client

  
Настройка брандмауэра (UFW)  
В Ubuntu за сетевой экран по умолчанию отвечает утилита UFW (Uncomplicated Firewall). Чтобы другие устройства из твоей локальной сети (Wi-Fi) могли подключиться к твоему прокси, нужно открыть порт 10809.  
Разреши входящие TCP-соединения на этот порт:  

sudo ufw allow 10808/tcp

  
_(Опционально)_ Если хочешь убедиться, что правило добавилось, введи:  

sudo ufw status

  
(Если статус "inactive", значит брандмауэр вообще выключен и порт и так открыт всем).  
Финал: Подключение  
Берешь любое устройство в твоей домашней сети, заходишь в настройки прокси (или настройки телеграма) и вводишь:  
**Тип:** SOCKS5  
**IP:** 127.0.0.1  
**Порт:** `10809  
**Пользователь:** `admin`  
**Пароль:** `admin`  
Готово! Вся система каскадной маршрутизации работает нативно.
